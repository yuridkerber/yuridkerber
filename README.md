## 📌 Projetos

### Omni — Atendimento inteligente de TI

Projeto desenvolvido durante o **Projeto Integrador da FATEC Araraquara**.

O Omni é uma solução de atendimento interno que utiliza Inteligência Artificial para auxiliar funcionários em solicitações de TI, realizando triagem, orientação e encaminhamento de chamados.

**Tecnologias e conceitos envolvidos:**

- TypeScript
- React
- Go
- PostgreSQL
- Ollama
- Modelos de linguagem
- REST API
- WebSocket
- Engenharia de Software
